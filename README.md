# BezotCorp Browser

BezotCorp Browser is an experimental open-source project aiming to build a high-performance, AI-ready browsing and workspace experience.

The project starts as a lightweight foundation and will grow progressively around:

- browser performance research;
- AI-native workflows;
- local bridge integrations;
- workspace-aware tooling;
- controlled rendering and virtualization;
- open-source extensibility.

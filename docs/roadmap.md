# BezotCorp Browser — Roadmap

## Milestone 0 — Foundation

- Initialisation du dépôt.
- Documentation du projet.
- Mise en place de la CI.
- Bootstrap de l'application Rust.
- Première fenêtre native.

## Milestone 1 — AI Workspace

- Interface de conversation.
- Historique local.
- Virtualisation native des longues discussions.
- Premier connecteur IA.
- Recherche dans les conversations.

## Milestone 2 — Local Bridge

- Bridge local sécurisé.
- Accès contrôlé au système de fichiers.
- Intégration avec les workspaces de développement.
- Communication avec les outils externes.

## Milestone 3 — Browser Capabilities

- Premières fonctionnalités de navigation.
- Gestion avancée des contenus web.
- Outils d'extraction et de transformation des pages.
- Optimisations natives des performances.

## Vision long terme

BezotCorp Browser a pour ambition de devenir une plateforme unifiée combinant :

- navigateur haute performance ;
- client IA universel ;
- environnement de travail développeur ;
- automatisation locale ;
- sécurité renforcée ;
- architecture ouverte et extensible.

Le projet sera développé de manière incrémentale, chaque étape apportant une valeur autonome sans attendre la réalisation de la vision finale.
